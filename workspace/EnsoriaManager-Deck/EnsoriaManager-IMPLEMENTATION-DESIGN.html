02 — Spazio Progetto

Il cuore dell'app: ogni progetto ha uno spazio dedicato con 7 aree

💬

Conversazioni Cross-Channel

Feed cronologico unificato. Origine: webchat, WhatsApp, email, social, Gmail. Ogni messaggio registrato con canale, direzione, metadata.

Gmail L/S WhatsApp Email

📎

Files & Links

Allegati, documenti, link di riferimento. File upload locale → cloud storage in produzione. URL tracking.

📋

Requirements / Needs / Goals

Bisogni, obiettivi, requisiti del cliente documentati e categorizzati. Tracciati con stato (open/in-progress/met).

🗺️

Roadmap & Milestones

Milestone con date, descrizione, stato. Timeline visuale. Scadenze e dipendenze tra milestone.

👥

Collaboratori

Chi lavora al progetto: interni + esterni. Ruoli, contatti, note. Collegamento a People DB.

📐

Project Plans

Piani operativi, documenti di progetto, strategy docs. Versionati e tracciati.

Analytics Layer

Dai dati raccolti si producono score numerici e trend

📈 Sentiment Score

Analisi del sentiment dalle conversazioni cross-channel. NLP-powered. Range: -1 a 1 → normalizzato 0-100

🎯 Alignment to Vision Score

Quanto il progetto è allineato alla visione del business. Basato su requirements/goals analysis

📉 Health Score

Trend, rischio, stato di salute generale. Composito da tutte le metriche

Estendibile — nuovi score possono essere aggiunti via plugin/moduli

Infrastructure

03 — Market Analysis

5 app simili analizzate — cosa copiare, cosa evitare, cosa migliorare

🔷

Twenty CRM

40.5K ⭐

Stack: React + NestJS + PostgreSQL + GraphQL

Da copiare: Custom objects/fields GUI, Email/Calendar sync, workflow builder, roles & permissions

Mancanze: No AI features, no charts nativi, no multi-tenancy

💬

Chatwoot

25K ⭐

Stack: Ruby on Rails + Vue.js + PostgreSQL

Da copiare: Inbox unificato cross-channel, agent assignment, automation rules, CSAT surveys

Perfetto per: Il nostro modulo conversazioni cross-channel

⚛️

Atomic CRM

MIT

Stack: React + shadcn/ui + Supabase + PostgreSQL

Da copiare: Solo 15K LOC, SSO/SAML, Kanban pipeline, mobile UI eccellente, MCP Server per AI

🐍

Frappe CRM

Open Source

Stack: Python + Vue.js + MariaDB

Da copiare: WhatsApp integration nativa

🔬 Customer Health Scoring (MCP Pattern)

Architettura: Multi-agent (data integration → analysis → recommendation)

Scoring: Usage (40%) + Relationship (30%) + Support (30%) → 0-100 composite

Soglie: Healthy 80-100 At Risk 60-79 Critical 0-59

Da copiare: Pattern per il nostro Analytics Layer

Database Schema (Prisma)

model People {
  id          String   @id @default(cuid())
  type        String   // staff | partner | freelancer | company | investor
  name        String
  email       String?
  phone       String?
  company     String?
  stage       String   // Contact | Opportunity | Client | Recurring Client
  tags        String[]
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
  
  projects    Project[]
  contacts    Contact[]
  activities  Activity[]
}

model Project {
  id            String   @id @default(cuid())
  name          String
  description   String?
  stage         String   // Contact | Opportunity | Proposal | Implementation | Onboarding | Live | Validated
  peopleId      String
  people        People   @relation(fields: [peopleId], references: [id])
  
  conversations Conversation[]
  files         ProjectFile[]
  requirements  Requirement[]
  milestones    Milestone[]
  collaborators Collaborator[]
  plans         ProjectPlan[]
  analytics     AnalyticsRecord[]
  
  createdAt     DateTime @default(now())
  updatedAt     DateTime @updatedAt
}

model Conversation {
  id          String   @id @default(cuid())
  projectId   String
  project     Project  @relation(fields: [projectId], references: [id])
  channel     String   // webchat | whatsapp | email | social | gmail
  direction   String   // inbound | outbound
  content     String
  metadata    Json?
  sentiment   Float?   // -1 to 1
  createdAt   DateTime @default(now())
}

model AnalyticsRecord {
  id              String   @id @default(cuid())
  projectId       String
  project         Project  @relation(fields: [projectId], references: [id])
  sentimentScore  Float?
  alignmentScore  Float?
  healthScore     Float?
  generatedAt     DateTime @default(now())
}

07 — Scoring Model

📐 Formula Composita

Health Score = Sentiment(30%) + Alignment(25%) + Progress(20%) + Engagement(15%) + Volume(10%)

📈 Sentiment Score (30%)

Da analisi NLP conversazioni

Positive > 65Good
Neutral 35-65Watch
Negative < 35Action

Conversazioni recenti pesano di più

🎯 Alignment Score (25%)

Requirements/goals vs business vision

Manual + AI-assisted scoring, trend tracking

📊 Progress Score (20%)

Milestones completati vs timeline

On-track / At-risk / Delayed

📊 Engagement + Volume (25%)

Frequenza interazioni + volume comunicazione

Engagement (15%) + Communication Volume (10%)

Soglie Standard

80-100 Healthy

60-79 At Risk

0-59 Critical

Implementation Summary

📦 What We're Building

CRM per tracciare People (staff, partner, freelancer, azienda, investor) che diventano Clienti, con Progetti aventi uno spazio dedicato a conversazioni cross-channel, files, requirements, roadmap, collaboratori e analytics.

🛠️ How We Build It

TypeScript full-stack: React + shadcn/ui + Express/Fastify + Prisma + SQLite. Architettura modulare predisposta per cloud migration (PostgreSQL). Pattern ispirati a Twenty CRM, Chatwoot, Atomic CRM.

📈 What Makes It Unique

Cross-channel conversation logging unificato, analytics layer con sentiment/alignment/health scoring, Gmail integration nativa, client portal gratuito, permission system multilivello.
